# openfiat-specs documentation

Extended documentation for `openfiat-specs` lives here. User-facing docs are
published to [docs.openfiat.network](https://github.com/OpenFiat-org/openfiat-docs)
— this directory is for documentation about the repository itself, not the
protocol (the protocol's documentation is the `Whitepaper/` directory one
level up).
